Background (verified in code, 2026-11-07): `nextMilestone` returns the lowest milestone whose `start` is not yet in `unlockedCheckpoints` (`src/meta/progression.ts:35`); milestone `{reach:10, start:4}` unlocks when `bestLevel >= 10` (`unlock`, same file). `Session.reached` skips only debug runs (`session.ts:83`). `HudScene.readHint()` re-reads the hint every time a new checkpoint is saved (`HudScene.ts:188-199`). So after a normal run reaches L10 the hint should read "Next checkpoint at L15", and the review's observation is probably a debug run (`?debug=1` / `debugSkipTo`, MEC-003-R21, which writes no progress). The tests below try to disprove that.
