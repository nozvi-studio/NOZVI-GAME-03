# Humor and tone ("bựa" layer)

## Rules

1. **Humor lives in reactions, not in the rules.** Jokes come from sounds, faces, words and
   side effects. Gameplay information stays clear.
2. **Never mock the player for losing in a way that feels cruel.** Mock the snake, the mango,
   the cat. Self-deprecating > insulting.
3. **Short.** Death messages ≤ 8 words. The player wants to retry, not read.
4. **Rotate.** The same joke 20 times is not funny. Every message type needs a pool of 5+
   lines, with no repeat twice in a row.
5. **Localize later.** Write jokes in a table (key → text) from day one so Vietnamese and
   English versions can live side by side. Wordplay rarely translates — accept separate jokes.

## Where humor goes

| Moment | Idea |
|---|---|
| Death by own tail | "Tasted like chicken." / "Self-cannibalism: not a strategy." |
| Death by wall next to a portal | "The portal was RIGHT THERE." |
| Death by fence | "Fence 1, Snake 0." |
| Mango rots | Mango makes a sad little "pfff" and a fly appears for 1 s |
| Golden mango | Snake wears sunglasses for 2 s |
| Tail Snip | "Snip!" + the cut tail runs away screaming (tiny "aaaa") |
| Slow-mo | Everything goes sepia, dramatic music sting |
| Headbutt | Cartoon stars around the head for the dizzy duration |
| Level 10 cleared | Snake does a dance; credits roll with mango names |
| Idle on pause screen | Snake falls asleep, "zzz" |

## Voice / art direction (to decide)

- Current prototype: soft flat colors, rounded font (Baloo 2), cute. Good base for "cute but
  silly" — contrast between cute art and cheeky lines is what makes it land.
- Avoid: humor that relies on specific memes or copyrighted characters (ages fast, legal risk).
